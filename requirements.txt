# OCR support for photographed receipts (HEIC/JPG/PNG/WEBP) — the one
# deliberate exception to this project's "no third-party packages" rule.
# PDFs and the rest of the pipeline stay pure stdlib without these.
# OCR runs fully locally via EasyOCR — no system-level engine binary to
# install (unlike Tesseract) and no cloud account/API key (unlike AWS
# Textract). First run downloads ~65MB of model weights to a local cache
# (~/.EasyOCR); every call after that is fully offline. See
# image_ocr.OCR_INSTALL_HELP.
#
# For deployment, use deploy_setup.sh instead of installing this file
# directly — easyocr pulls in torch, whose wheel ships several hundred
# MB to several GB of build-only artifacts (static-link .lib/.a stubs,
# C++ headers) that are dead weight for plain CPU inference. That script
# installs a CPU-only torch build and then runs
# scripts/cleanup_torch_bloat.py to strip that dead weight.
